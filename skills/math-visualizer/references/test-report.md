## 结论与范围

已把单题生成流程做成可发现的 Skill，随包提供教学设计规范、模型与状态约定、工具选择表、SVG/空间投影工具、课堂样式、步骤壳、单文件打包器、可移植自检与完整案例。

从用户指定的 deekur/gaokaomath 仓库抽取 2022—2026 年全国1/新高考I卷，每年两个测试单元，共10个。7个交互讲解，1个静态分类表，2个无需绘图的解答。2024第19题只测第（1）问。另有一个人为缺失符号的输入门禁测试，不计入十个真题单元。

这不是近五年全部试卷验收，也不是学生学习效果实验。两道空间题由独立执行者只读取Skill与原题完成，其余八题为主Agent自测；代码另经独立审查。

## 程序与行为证据

- 工具测试8项：等比例、断段、标签钳制/冲突、原点不误移、远标签引导线、精确分数/近似、空间向量、SVG转义与ID。
- 步骤/模型测试3项：68组图形与解释状态、初始答案揭示、前后切换、键盘控件节点身份与重置保留步骤。
- 打包测试3项：真实嵌入、拒绝网络及覆盖源文件、拒绝不支持的模块/属性语义。
- 空间题80组状态：两视角、步骤、候选高度/边界；真实角度/距离、有限坐标、几何视窗内、无省略标签。
- SymPy精确运算及Python组合/序列枚举核验8个自测题；一般推理仍保留在各题analysis，不把程序采样冒称证明。
- 缺符号测试返回 blocked：要求补待证关系及点定义，没有猜补为先前见过的题，也没有生成替代页面。

## 浏览器检查

Chrome中实际打开十个案例。逐步操作了七个交互页；检查了分段参数反例、重置不退步、圆在r=1和r=3的相切计数、球编号切换及末步控件隐藏、离散删项、函数对称/切线、空间换视角和二面角截面。三道静态/不绘图页核查了可见解答和分类表。

1366×768下检查代表页面的图文同屏；截图发现的标签与视窗问题已反馈修复。390×844视窗复核2024/6、2023/18截面、2026/15终态，三者文档可用宽度与滚动宽度均为375px，没有横向溢出。截图复核分段函数与2026空间题，发现手机继承桌面图卡最小高度造成空白，已取消窄屏最小高度并允许参数标签换行；修复后分段函数图卡高度约240px。临时视窗设置已恢复。此前自动批量跨视窗检查超时，未将未返回的结果计作通过；没有宣称十题全部手机状态验收。

## 发现的问题及回写

| 来源 | 问题 | 修订 |
| --- | --- | --- |
| 旧案例评审 | 结论提前出现在顶点标签/caption/公式 | 流程要求所有通道服从揭示状态 |
| 旧案例评审 | 口诀替代解释；图主要画结果 | 教学关键句、对应点、预测问题与因果观察任务 |
| 旧案例评审 | 变式图与原题正文混用 | 同一模型派生；原题/候选/变式/视角分别定义 |
| 旧案例评审 | 近似数写成精确等式 | 精确表达与近似显示分开 |
| 独立审查 | 打包丢模块或media属性 | 不支持的语义明确拒绝；复杂库先专用打包 |
| 独立审查 | 工具测试依赖项目外目录 | 测试迁入Skill，项目仅保留入口 |
| 独立审查 | 概率末步仍留无效控件 | 控件支持from/to，按观察任务显示 |
| 浏览器 | O标签被避让到其他坐标附近 | 轴标签固定；远标签加引导线，新增回归测试 |
| 浏览器 | 空间实体在大卡片中仍很小 | 合法对象预计算固定视窗，截面独立放大，保持等比例 |
| 浏览器 | 圆心与原点可能同名 | 明确圆心C，并配文字/线型解释 |
| 手机浏览器 | 图卡空白过多、长参数标签紧凑 | 窄屏取消最小高度，标签允许换行，补入流程验收 |

## 重现

在项目根目录运行：

```powershell
python tests/gaokao/build_cases.py
python tests/gaokao/check_math.py
node --test tests/toolkit.test.cjs tests/gaokao/state.test.cjs
python tests/test_bundle.py
python tests/gaokao/spatial-check.py
python skills/math-visualizer/scripts/bundle.py tests/gaokao/output/2023-q18/index.source.html tests/gaokao/output/2023-q18/index.html
python skills/math-visualizer/scripts/bundle.py tests/gaokao/output/2026-q15/index.source.html tests/gaokao/output/2026-q15/index.html
python tests/gaokao/finalize_package.py
python skills/math-visualizer/scripts/check_package.py skills/math-visualizer
```

数学核验脚本需要SymPy；浏览器产物无外部依赖。Skill单独复制后，从Skill根目录运行 `node --test scripts/toolkit.test.cjs` 和 `python scripts/check_package.py`。
