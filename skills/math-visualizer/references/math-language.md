# 数学教材语言与表述规范

用于编写与交付前独立教学审校。目标是符合中国大陆相应学段数学教材常用的中文表达，准确、自然、可理解；不能只检查答案是否正确，也不能把所有句子改成同一种文风。

## 依据与适用范围

- 先依据原题、教学目标和已声明的前置知识确定学段。用户指定教材时，沿用该教材的术语、符号和定义约定；未指定时按相应学段通行表述，不默认某出版社唯一正确，不为普通题强制追问版本。
- 对具体版本的术语差异、定义范围或“现行教材已这样规定”的判断，查用户提供的教材原页或出版社、课程标准的正式材料，记录版本/章节或来源。未取得材料时，说明未对照该版本，不能编造教材规定或仅凭印象判错。已知数学或语法错误仍须修正。
- 以学生正文、标题、提问、公式、图中标签和操作提示为检查对象，连读前后步骤并检查参数分支。导航标签、图注和公式允许使用约定俗成的简短形式；完整推理不能被压缩成必须由教师猜补的提纲。

## 逐项检查

1. **术语与学段。** 区分函数与函数值、方程的根与函数的零点、极值与最值、线段与长度、向量与模、概率与频率等对象；不混用相近名词。采用该学段已学术语，新术语先说明含义。不用未介绍的高阶概念代替学生需要理解的推理，例如不能只用“上确界”三个字解释左段函数值的界限。
2. **句法与搭配。** 主语与谓语相配，关联词前后结构完整，修饰关系明确。例如“点到直线的距离等于 1”，不能写成“点要到直线的距离为 1”。检查成分残缺、句式杂糅、不当省略、错别字和改变句意的标点。不能以“看得出大概意思”放过可明确定位的病句。
3. **对象与指代。** “取、设、作、连接、过……作……”须说明对象、约束和必要的构造关系；“它、这条线、另一段”须有唯一指代。点 P 与长度 OP、横坐标 x 与函数值 f(x) 不互相替代。术语正确但整句没有明确对象，仍不合格。
4. **逻辑与量词。** “任意/所有”“存在/至少一个”“唯一/恰有一个”准确对应命题；保留取值范围、量词顺序与依赖关系。区分“若……则……”“只有……才……”“当且仅当”，不能把充分性当必要性或把单向推出写成等价。一个实例或图形观察不能写成一般证明。
5. **符号与文字。** 等号、不等号、蕴含、等价及近似号与文字一致；等式两边对象类型相容，区间端点、单位及定义域明确。近似数写“约”或用 ≈；规范的公式、∵/∴、导航短标签不因不是完整汉语句子而被判错。
6. **推理与语体。** 根据前置知识补齐必要条件与承接，明确“由什么得到什么”。观察阶段可用“碰到”等直观说法，正式结论要落到相交、相切或公共点等准确关系。教师安排和实现说明放在备课区，学生提问直接面向当前数学任务；不得用工程术语或临时自造简称替代必要的数学解释。

## 判定和修改

**必须修复，阻止正式交付：** 能指出具体成分或关系的病句；术语、符号、量词或逻辑关系用错；歧义导致对象无法唯一确定；缺失必要条件或推理；经材料核实违反本任务所用教材的定义/表述约定。语言问题即使没有改变最终答案，也不能自动降为表达偏好。发现应引用原句，指出哪里不成立，给出依据及保留原意的修改建议。单说“不像教材”“不够顺口”不构成依据。

**可保留，非阻止建议：** 原句准确自然、对象明确，仅存在多种合格说法；在当前上下文中可理解的课堂口语；非必要的扩写、语气、长短和排版偏好。不能建立“贡献、碰到、显然”等脱离上下文的禁词表，也不强制每句使用“因为……所以……”。同义改写不应被当作必修问题。

**需要核实：** 判定取决于教材版本而没有原文依据时，记录待核实事项，不能声称已完成教材对照。它若影响定义、适用条件或当前推理的成立，先解决再交付；仅属不同教材均可接受的措辞差异，不凭偏好阻止交付。

| 原句及上下文 | 判断依据 | 合适的处理 |
| --- | --- | --- |
| “点 P 既要在圆上，又要到直线 l 的距离为 1。” | 后半句把“点 P”与“到直线的距离为 1”杂糅，搭配不成立 | “点 P 在圆上，且点 P 到直线 l 的距离等于 1。” |
| 已求得 x²−1=0 的两个解后写“函数 f(x)=x²−1 的两个零点是 (−1,0)、(1,0)” | 把自变量的值写成图像上的点 | “函数的零点是 −1 和 1；图像与 x 轴的交点是 (−1,0) 和 (1,0)。” |
| “由 a≤0，得 a≥−1，所以 a∈[−1,0]”，实际第二个条件来自另一步 | 把两个独立条件错写成推出关系 | 分别交代条件来源，再写“综合两项条件，得 −1≤a≤0”。 |
| “取 x=1，得到 x²>0，因此任意实数 x 都满足 x²>0” | 个例不能推出全称命题，且 x=0 是反例 | 修正命题范围，并给出一般理由，不能只润色句子。 |
| “任取 x₁、x₂∈I，且 x₁<x₂”，I 已明确 | 对象、范围与比较关系明确，属于合格的简洁表述 | 保留；不强制改写成更长的口语句。 |

审校响应沿用教学审校协议的 findings 结构；`type` 按实际问题选语言、推理、图文或数学，`basis` 写具体依据，`suggestion` 不得偷改原题。响应 notes 说明所用学段、教材依据/是否指定版本，以及未完成的对照范围。未发现问题不必凑数。

## 参考边界

本文件是项目的审校标准，不是某一本教材的逐字引文。量词部分可参照人教社高中数学 B 版[《1.2.1 命题与量词》教学材料](https://www.pep.com.cn/gzsxb/xrjbgzsxb/xrjgsbwd/201909/t20190903_1944846.html)：同一逻辑含义可以有不同的自然语言表述。该材料支持区分量词含义与表面措辞，不代表核对了所有版本的现行教材。只有具体判定需要时才查相关材料，不把联网检索设为每题的固定前置步骤。
