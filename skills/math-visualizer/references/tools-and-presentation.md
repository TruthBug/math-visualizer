# 工具与呈现选择

## 按需要看见的关系选工具

| 题型/障碍 | 首选呈现 | 工具 | 特别检查 |
| --- | --- | --- | --- |
| 函数平移、周期、导数 | 对应点、切线、增减区间；必要时两个协调面板 | 内置 SVG | 坐标比例、定义域、断点、精确值、区间端点 |
| 分段函数 | 分段曲线 + 接缝左右值 + 数轴 | SVG | 空实端点、两段单调不能替代跨段条件 |
| 圆锥曲线、轨迹、距离 | 约束动点、直线、距离/弦长、辅助构造 | SVG；复杂多约束可选 JSXGraph | 原题约束始终成立、相切/退化单列、别由结论构图 |
| 平面几何证明 | 必要辅助线、全等/相似对应、构造次序 | SVG | 图不是证明；只标已知及当前已推出的关系 |
| 空间线面关系/角/截面 | 可旋转实体 + 必要的正交截面/向量式 | 内置 project3 用于简单线框；复杂曲面/遮挡选 Three.js | 投影不保角，隐藏线须说明；真实角度在空间计算 |
| 三角函数 | 单位圆与函数图联动，或只显示关键区间 | SVG | 弧度、周期、符号、渐近线、不靠采样数交点 |
| 概率与统计 | 样本表、树图、比例条；条件化后样本空间变化 | SVG/HTML 表格 | 概率质量守恒、同尺度、抽样≠解析概率 |
| 数列、排列组合 | 下标卡片、分组、面积/数轴（确有对应时） | HTML/SVG | 离散变量不画连续连线；枚举有限 n 不证明所有 n |
| 简单复数/集合/代入 | 短公式或静态数轴 | HTML/MathML | 若图不减少理解难度，判 none；不要硬加复平面 |

SymPy 可用于因式分解、导数、精确求解与代数恒等核验；Python 标准库适合有限枚举；数值求根/采样用于辅助发现与交叉检查，不能替代根个数或一般证明。

## 使用内置工具

教学表示明确后，按 [复用与扩展](reuse-and-extension.md) 选择配置、组合或扩展。模块完整匹配时只写 JSON 并用 `build_lesson.cjs` 构建。下面的低层流程也可直接组合现有图形能力完成任务，不要求先开发公共模块；只有配置不足且确需组合/特殊呈现时才读取。

查 [toolkit-api.md](toolkit-api.md) 中所需 API，不预读整套实现。低层组合的基本构建流程：

1. 写 HTML，`<link data-bundle href="../assets/classroom.css" rel="stylesheet">`，`<script data-bundle src="../assets/mathviz.js"></script>`。
2. 编写题目自己的数学模型与呈现，不把图形库当求解器。
3. `python scripts/bundle.py input.html output.html` 嵌入带 `data-bundle` 的资源，保留源文件便于修订。
4. 单文件输出不依赖网络。外部库若必要，固定版本、本地打包、保留许可；不可只插 CDN 却声称离线。

正式交付前同样冻结源稿、做独立教学审校并留存实际渲染证据；低层打包器不自动执行审校门禁，不能以打包成功代替通过。使用临时预览试作，通过后再生成正式产物。

内置 bundle.py 只接受无额外属性的经典脚本和 rel=stylesheet 样式；遇到模块、CSS url()/@import、media 等属性会拒绝，避免静默改变语义。Three.js/公式库及其依赖先用专用构建器打包，再验证最终离线资源。lesson.js 是**已冻结**的可选步骤壳（2026-09-19 起不再演进，仅作低层组合参考）：controls 可用 from/to 限定有效步骤，恢复参数保留步骤；完整用法见配套案例。新任务优先用配置路径；题目不需要控件时不要仅为复用壳而添加控件。

**统一课堂壳**：所有页面共用 classroom.css 的页面框架——品牌页眉（∩ 数学 · 交互讲解 + edition + 备课提示开关 #notes-toggle/#notes）、引言区（eyebrow + h1 + 可选衬线公式 .equation）、图解区（.stage/.visual）、参数栏（.parameter-bar：滑块 + stops 代表位置 + 恢复参数）、步骤页脚（footer：.steps 标签页 + 重新讲解 + ←/下一步）。player.js（配置路径）填充步骤标签页、stops 与开关行为；已冻结的 lesson.js 行为相同，仅历史页面使用。steps 的 tab 短名由步骤的 tab 字段提供（缺省只显序号）。新页面按模板的 id 契约提供容器（steps、controls、notes-toggle、notes、footer 等），不要另造页眉、页脚或步骤导航样式。

公式排版分两级：展示级公式（页首 .equation，衬线 Georgia + <sup>/<sub> 标记）用于题目的核心等式，由配置/case 的 equation 字段提供，内容不得泄露待求结论；步骤内公式块（.formula）与行内提及用无衬线 + Unicode 上下标，保证字形覆盖一致。复杂分式/矩阵优先本地 KaTeX/MathJax。不得让“用轻量工具”迫使公式变得难读。示意图需要数学准确，生成式图片不能替代确定性几何绘制。

## 视觉规范

- 视觉语言以统一课堂壳为准：配色角色 --blue（主对象）/ --orange（比较与参数对象）/ --green（结果与辅助线）/ --ink（正文）/ --muted（次要文字），页眉细线分隔、无卡片堆叠；新页面沿用这些角色，不自创配色或控件风格。
- 继承统一的色彩角色：主对象、比较对象、当前关系；至少同时用标签/线型区分。图例只显示当前存在的对象。
- 课堂视图优先图与当前解释同屏。把完整题干/长推导放可展开区，但当前待求目标及理解它所必需的条件要直接可见，不能只留一个“查看题目”入口。不要让步骤目录挤走正在讲解的内容。
- 1366×768 和 1920×1080 检查图、关键公式、操作；窄屏可上下排列。不要通过整体缩小字体掩盖溢出。字号是起点，投影可读性仍需看实际效果。
- 关键公式约 24px 起，正文约 20px 起；SVG 显示缩放后仍要可读。重要关系优先于网格、装饰、页眉。
- 选与目标关系相称的固定视窗，比较状态间不要悄悄改变比例。必要时显式提供“适合视野”。视野外对象不能静默消失。
- 标签避让、钳制边界、合并重合点。工具若省略冲突标签，作者须读 collisions 并保留文字解释，不能把省略当全部通过。
- 不自动播放或无限循环；构造、平移可前进/回退/重置。简单离散揭示可以不用动画。
- 三维线框若不判遮挡，明确说明全部棱可见；不要把实线/虚线伪装成正确遮挡。复杂情形换专用渲染器。

页首揭示约定：teaching.objective 属于教师备注，不能自动作为学生页首文案。真题 key 是讲解依据，不作为常驻标题。equation 仅放已知或设问；指示变量分解等新方法须在定义之后揭示。equation 支持无属性的成对 sup/sub，比较符按文本显示，其他标签构建失败。tab 在两条播放器路径均可选，缺省显示序号。
