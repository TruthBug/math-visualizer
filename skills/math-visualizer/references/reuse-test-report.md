# 配置复用版本验证

本轮实现两种数学能力模块、共享播放器、JSON 校验与离线构建。使用相同工程代码生成二次函数课件和2025高考圆题；题目专属输入为JSON，无专属JS或HTML。核心版本2.0.0，模块版本1.0.0。

运行 `node --test scripts/modules.test.cjs scripts/toolkit.test.cjs`：13项通过。新增测试覆盖开口朝上/朝下与不同顶点的求根代入、圆题临界计数与十进制相切、非法配置拒绝、输入文件保护、数据嵌入、两个场景导航/参数保留/重置和控件节点稳定。纯DOM替身测试不冒称真实浏览器测试。

真实Chrome检查两个生成页面：圆题第二步r=3显示3个交点，恢复参数仍停第二步；截图检查图、解释、关键位置按钮。二次函数第二步k=0显示1个交点，键盘左键到−0.25显示0个交点。浏览器发现近似绑定出现“=≈”连用，已在公共绑定函数修正。未完成本版本全部手机状态验收。

独立审查发现并修复：刻度在极大坐标下浮点递增失效、十进制相切误计、构建记录覆盖输入配置。对应加入回归测试。独立前向生成因用量限制中断，不能计作通过；本版生成与组合验证属于主Agent自测。

仍有限制：圆相切容差是数值展示约定，不是精确几何证明；静态题干与公式仍需逐题核验。多个场景串联已经实现，同时双画布联动、复杂3D工具接入尚未实现。旧十个案例保留为教学参考，尚未全部迁移为配置模块。
